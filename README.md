# Saffron Table — Restaurant Website

A premium, lightweight restaurant website built with HTML5, CSS3, vanilla JavaScript and Tailwind CSS via CDN.

## Pages
- `index.html` — Home
- `menu.html` — Menu
- `about.html` — About
- `contact.html` — Contact

## Run locally
Open `index.html` directly in a browser. No build step, backend or database is required.

For the best local development experience, use VS Code + Live Server.

## Before client launch
Search and replace these demo values:
- `Saffron Table`
- `+91 90000 00000`
- `Main Market Road, Your Town, West Bengal`
- WhatsApp number `919000000000`
- Google Maps location in `contact.html`
- `https://example.com/` canonical URL
- Menu names/prices
- Food and restaurant photos
- Opening hours

## Notes
The site uses Tailwind CSS, Google Fonts and Unsplash-hosted photography through external CDNs. If the final client site needs fully offline assets, download and self-host the images/fonts before delivery.
